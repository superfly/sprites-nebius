# Security policy

This toolkit configures coding agents and a local adapter for inference through
Fly.io Sprites connectors. Treat credential leakage, routing-policy bypasses and
unsafe configuration or service cleanup as security issues.

Report suspected vulnerabilities privately to [security@fly.io](mailto:security@fly.io)
with `sprites-nebius` in the subject. Do not open a public issue or PR.
Include the affected commit, expected security boundary, minimal reproducer and
potential impact. Remove live keys, private identifiers and unrelated customer data;
test only in environments you own or are authorized to use.

Security fixes target `main`. See [Fly.io's security guidance](https://fly.io/docs/security/security-at-fly-io/)
for the broader platform policy.
